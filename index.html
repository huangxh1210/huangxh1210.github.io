PROJECT 01 2026.07 — 2026.08

基于 ESP32-S3 的高性能便携游戏主机

从电源与 PCB 设计到固件开发的全流程自制掌上红白机：移植 NES 模拟器核心，支持 WiFi 网页上传 ROM，免拆机更新游戏。

MCU
ESP32-S3 · 8MB PSRAM
DISPLAY
ST7789 · SPI
AUDIO
MAX98357A · I2S
INPUT
74HC165 按键扩展
POWER
5V / 3.3V 双路 DCDC
EMULATOR
nofrendo · 40+ mapper
HIGHLIGHTS
  • 硬件设计——完成双路 DCDC 电源设计与整机原理图、PCB 布局布线（优化大电流走线、电源环路与散热），打样焊接并验证电路稳定。
  • 外设与资源——驱动 ST7789 屏、MAX98357A 音频、74HC165 按键扩展；定制 Flash 分区表，配置 8MB PSRAM 并修复缓存一致性问题。
  • 模拟器与功能——移植 nofrendo 核心，适配 6502 CPU、PPU / APU 及 40+ mapper；自研中文 ROM 菜单（脏矩形刷新）与 WiFi 网页 ROM 上传。
  • 硬件排障——定位并修复屏幕 BGR 色序反相、I2S 单声道无声、PSRAM 缓存异常等硬件级问题。
STACK
PlatformIO C++ ESP32-S3 TFT_eSPI nofrendo 嘉立创 EDA
PROJECT 02 2026.05 — 2026.06

基于 STM32F407 的智能停车场管理系统

以 STM32F407 为主控，集成 RC522 射频读卡、MaixCAM 车牌识别、红外检测与舵机道闸，配套上位机构建完整停车收费系统。

MCU
STM32F407 · 标准外设库
RFID
RC522 · SPI
VISION
MaixCAM 车牌识别
ACTUATOR
SG90 舵机 · PWM
HOST
Python · Tkinter · SQLite
LINK
自定义串口协议
HIGHLIGHTS
  • 外设驱动——编写 RC522（SPI）射频读写、OLED、SG90 舵机（PWM）、红外检测等驱动，基于 TIM2 构建 1ms 系统时基。
  • 通信协议——自定义串口通信协议（0xAA / 0x55 帧头，含心跳、进出场、计费等 20+ 命令字），实现 STM32 与上位机双向数据同步。
  • 上位机——Python（Tkinter）+ SQLite 开发管理上位机，实现卡片管理、计费配置、进出场记录查询。
  • 业务流程——打通车辆进出场识别、车牌绑定、余额计费、道闸开合与 OLED 显示的完整流程。
STACK
